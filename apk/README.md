# Juice Therapy – Android App

Install the staff task manager on Android phones.

## Download

**APK file:** [JuiceTherapy-TaskMan.apk](./JuiceTherapy-TaskMan.apk)

Or open on the phone:  
https://titir95biplab-dotcom.github.io/JT-s-TaskMan/apk/JuiceTherapy-TaskMan.apk

## Install steps (Bengali / English)

1. Phone এ উপরের APK link খুলুন / download করুন  
2. যদি block করে, **Settings → Security → Install unknown apps** থেকে browser/file manager allow করুন  
3. APK tap করে **Install** চাপুন  
4. App খুললে outlet select করে login করুন (JT BIRATI / JT NIMTA)
